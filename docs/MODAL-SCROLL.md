# Scroll halaman saat dialog terbuka

Root layout memasang satu ModalScrollLock untuk seluruh aplikasi. Native dialog dengan atribut open dan dialog custom dengan aria-modal=true memakai lock yang sama. Body dipasang fixed dengan offset scroll halaman; root dikunci overflow-nya. Saat seluruh dialog ditutup, posisi, lebar, overflow dan scroll dikembalikan. Perpindahan detail native ke form edit custom mempertahankan lock; efek overflow dialog lama tetap didukung. Konten dialog memakai overscroll-behavior:contain untuk mencegah scroll menerus ke halaman belakang.

Validasi: lint dan build berhasil. Empat skenario browser lokal unik berhasil: tabel/dialog pelanggan, detail mobile, penguncian scroll Jastip dan Open PO. Dua tes penguncian memakai viewport 390×700 dan halaman panjang, memeriksa posisi halaman setelah membuka detail, wheel pada backdrop, perpindahan ke edit, scroll isi form, pengembalian posisi saat ditutup, serta scroll halaman kembali aktif. Tes PO awal mencari nama tombol close Jastip; selector diperbaiki agar mencakup nama PO dan lulus. Browser memakai Chromium dengan mock Supabase, belum pengujian perangkat Safari/iOS fisik. Deployment Vercel belum diverifikasi.
